# Credits

The bot's avatar (`assets/avatar.png`) is original, drawn for CodePlate by `scripts/make-avatar.ts` (shapes in an SVG, rendered in code; no source images). It's listed in `assets.json` with `license: CodePlate-original` and is yours to use for bots made from this template.

The screenshot tool (`scripts/preview/`) draws an approximation of a chat client's dark theme with its own CSS; it uses no images, fonts or code from Discord.

When you add assets, list each one in `assets.json` (path, size, where it's used, license, credit) and here, with its author, license and a link to its source. Only use assets the user owns, made themselves, or that are CC0.
